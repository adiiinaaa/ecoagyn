# EcoAgyn

Веб-приложение (Python + Streamlit): подсчёт машин по видео (YOLO11 + ByteTrack),
математический расчёт топлива, CO2 и загрязнителей
(CO, NOx, PM2.5 и др.) по официальным коэффициентам, анализ неопределённости,
статистика потока, сценарии «автобус вместо машины» и экологический итог.
Интерфейс — на казахском языке. Основа подсчёта — проект TCounter.

## Установка (Windows, один раз)

Нужен Python 3.11+ (проверено на 3.14) и, желательно, видеокарта NVIDIA.

```powershell
cd C:\Users\acer\Documents\TCounter\ekoagyn
python -m venv .venv
.\.venv\Scripts\activate
# PyTorch с поддержкой видеокарты (CUDA 12.8, подходит для RTX 50xx):
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
```

Без видеокарты: `pip install torch torchvision` (будет работать на процессоре, медленнее).

При первом запуске автоматически скачиваются модели:
YOLO11s (~19 МБ, в папку `models/`).

## Запуск

```powershell
.\.venv\Scripts\activate
streamlit run app.py
```

Сайт откроется по адресу http://localhost:8501.

## Как пользоваться

Меню разбито на группы: **Талдау → Математика → Экология → Әдістеме**.

**Талдау (анализ)**
- **Бейне және санау** — слева крупный кадр, справа настройки. Выберите видео из папки `videos/`
  (или `../videos/` проекта TCounter) либо загрузите mp4/mov. Кликните по кадру точки A и B — это линия
  подсчёта; «Бағыт» меняет направления местами. Нажмите «Талдауды бастау».
  Ноутбук лучше подключить к зарядке: на батарее видеокарта сильно замедляется.
- **Дәлдікті тексеру** — ручной подсчёт за отрезок видео (ε) и проверка типа транспорта по вырезкам
  (матрица ошибок, accuracy, precision, recall, F1).

**Математика**
- **Ағын статистикасы** — интервалы 30 с, x̄, s², индекс дисперсии, Пуассон и χ², сравнение видео.
- **Шығарындылар есебі** — формулы и пошаговый расчёт с подставленными числами; длина участка L; модели 0 и 1.
- **Белгісіздік** — сценарии low/base/high, торнадо, Монте-Карло (10 000), вклад источников.
- **Сценарийлер** — доля p поездок, перенесённых в автобус; сценарии А и Ә; точка безубыточности n*.

**Экология** — итоговые карточки, эквиваленты (EPA), выводы и рекомендации.

**Әдістеме** — «Қалай есептелді?»: все формулы, параметры с источниками, допущения.

Блок **«Ағымдағы жоба»** внизу меню: выбор обработанного видео и кнопка «Есепті дайындау»
(HTML-отчёт и zip с PNG для стенда).

## Где результаты

`results/<имя_видео>/`:
`summary.json`, `events.csv` (каждая машина), `per_30s.csv`, `per_minute.csv`,
`crops/` (вырезки с размытыми номерами — для проверки точности),
`annotated.mp4`, `stand_frame.png`, `png/` (все графики, 300 dpi),
таблицы расчётов (`emissions_*.csv`, `monte_carlo_stats.csv`, …),
`report_<видео>.html`, `stand_png_<видео>.zip`.

## Параметры и источники

Все коэффициенты — в `config.json`, у каждого есть поле с источником
(EMEP/EEA Guidebook 2023 – Update 2026, IPCC 2006, U.S. EPA, EEA TERM 029, UK DfT).
Любое значение можно изменить в интерфейсе (раздел 4) — config.json хранит только значения по умолчанию.

## Конфиденциальность

Номера машин не распознаются и не сохраняются. На всех сохраняемых кадрах, вырезках и в видео
зона номера (нижняя часть рамки машины) и головы людей сильно размываются.
